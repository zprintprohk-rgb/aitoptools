### 1.2 DNS 解析对比 (根因)

```python
default getaddrinfo('imap.gmail.com', 993)        → 142.250.157.108/109 (Google 真实) → TCP 0.07-0.20s OK
AI_ADDRCONFIG getaddrinfo('imap.gmail.com', 993)  → 64.233.189.108/109  (GFW 污染)   → TCP timeout
```

→ **根因**: GFW DNS 污染. AI_ADDRCONFIG flag 命中污染池, default flag 走真 IP.
→ imaplib 内部用 socket.create_connection (走 system DNS 受 GFW 影响) → 命中污染 IP → fail
→ **fix**: 显式 `socket.getaddrinfo(host, port, AF_INET, SOCK_STREAM)` 拿真 IP, imaplib 用 IP 而非 hostname
